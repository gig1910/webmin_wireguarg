# UN/LOCODE для городов WireGuard

Модуль различает две задачи: **GeoLite2 City** приближённо определяет город
публичного IP, а **UN/LOCODE UNECE** даёт стандартизованный код найденного
населённого пункта. Геолокация не определяет точное местонахождение устройства.

Например, `RU + Moscow` сопоставляется с `RUMOW`: в таблице будет
`MOW`, в подсказке — полное имя города и `RUMOW`.
`MSK` не используется как официальный UN/LOCODE.

## Автоматическая установка и обновление

UN/LOCODE — необязательный справочник. Во время установки модуля
`postinstall.pl` создаёт собственные **systemd service/timer**:
`webmin-wireguard-unlocode.service` и
`webmin-wireguard-unlocode.timer`.

- Первая загрузка запускается **асинхронно** после установки — установка
  Webmin не ждёт ответа UNECE.
- Таймер проверяет обновления ежемесячно, с произвольной задержкой.
- При обновлении самого модуля недавно обновлённый справочник не
  загружается повторно.
- Рабочий обработчик загружает ZIP **только по HTTPS с домена UNECE**,
  ограничивает размер данных и проверяет полноту выпуска перед импортом.
- Если файл недоступен, база повреждена или ZIP неполный, предыдущий
  справочник остаётся в SQLite. Отказ не влияет на работу WireGuard.
- На странице «Значки сетей и кеш диапазонов» доступны количество записей,
  дата успешной загрузки, последняя ошибка и кнопка
  **«Обновить UN/LOCODE сейчас»**.
- При удалении модуля управляемые systemd units удаляются; база
  статистики, кеша и UN/LOCODE остаётся сохранённой.

Для ручной диагностики на сервере:
```sh
systemctl status webmin-wireguard-unlocode.timer
systemctl status webmin-wireguard-unlocode.service
journalctl -u webmin-wireguard-unlocode.service -n 50 --no-pager
```

Сетевые ZIP-архивы берутся из официального каталога UNECE:
https://unlocode.unece.org/publications/ .
Доступность конкретного production-архива следует проверить в реальном
сетевом окружении сервера, поскольку CI использует офлайн-фикстуру.

### Резервный ручной импорт

Если сеть ограничена или формат выпуска изменился, сохраняется возможность
загрузить официальный CSV/ZIP самостоятельно и выполнить:
```sh
python3 /usr/share/webmin/wireguard/scripts/import-unlocode.py \
  /var/webmin/wireguard/stats/analytics.sqlite3 /path/to/UNLOCODE.zip
```

Ручной импорт не делает исходящих сетевых запросов. Перед прямыми
операциями с SQLite рекомендуется резервная копия.

## Правила выбора

- Пара `страна (ISO 3166 alpha-2) + город` нормализуется и ищется
  по основному названию или латинскому написанию в UN/LOCODE.
- При **ровно одном** совпадении сохраняется пятисимвольный код.
  При отсутствии записи или неоднозначности код оставляется пустым.
- Неизвестные города не получают выдуманных трёхбуквенных кодов.
- В сетевом справочнике можно вручную задать название и полный
  пятисимвольный UN/LOCODE, например `RSBEG`; код должен существовать
  в загруженном каталоге. Такое назначение сети имеет приоритет над GeoIP.
- Кеш города привязан к конкретному публичному IP, а не ко всему
  WHOIS-диапазону. Сброс кеша не удаляет ручные назначения и UN/LOCODE.
- Ранее кешированные IP могут получить коды после импорта справочника
  при очередной загрузке таблицы — массовых сетевых запросов не производится.

Для автоматического определения **города** необходимо настроить MaxMind
GeoLite2 City. В Webmin откройте «Значки сетей и кеш диапазонов»,
затем «Установить GeoLite2 City из Webmin». Если пакет geoipupdate отсутствует,
мастер предложит его установить. При первой настройке необходимы
MaxMind Account ID и License Key; если они уже сохранены в GeoIP.conf,
их можно не вводить повторно. Лицензионные реквизиты не хранятся
в конфигурации самого модуля WireGuard.

Данные UNECE используются локально. Для городов из GeoLite2 нужен
отдельно установленный `GeoLite2-City.mmdb` и `mmdblookup`.
Country-only база не содержит названий городов.

Проверки: `python3 tests/analytics-store-test.py`,
`./tests/run-tests.sh`, `./scripts/build-release.sh`.
